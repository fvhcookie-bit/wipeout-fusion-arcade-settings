# Changelog

## 1.1 — 2026-10-19
- NTSC-U release (SLUS-20462, CRC 4C2D1E6D) supported: `patches/4C2D1E6D.pnach`. Tested in PCSX2 2.8, also
  together with the built-in Widescreen and No-Interlacing patches.
- New optional entry: Skip intro movies (both releases).
- FINAL LAP fix: marked as needed only on older PCSX2 versions; the alpha experiment entry removed.
- The Arcade patch is now also applied when the game is loaded, so it works when the intro movies are skipped.

## 1.0 — 2026-10-19
- Arcade race set-up screen after ship select: laps, 6–16 ships, player and CPU shield, CPU upgrade level and
  race class, pit lane, player respawn, catch-up, destroyed CPU ships (out / respawn / wreck).
- FINAL LAP fix: 1 echo layer, alpha cap, or no FINAL LAP text (optional entries).
- Tested in PCSX2 2.8 with the PAL release (SCES-50005): Arcade with every option, League races unchanged.
