# WipEout Fusion — настройки аркадных заездов (патч для PCSX2)

Патч для **WipEout Fusion** (PAL и американской NTSC-U) в эмуляторе PCSX2. В одиночной **Arcade** после выбора корабля
открывается экран **race set-up**. На нём можно выставить:
- число кругов;
- число кораблей, до 16;
- щит свой и соперников;
- уровень прокачки соперников (можно сильнее твоего корабля);
- пит-лейн, воскрешение игрока и резиновую нить;
- что делать с уничтоженными соперниками: выбывают (**out**), воскрешаются (**respawn**) или остаются на
  трассе неподвижными остовами (**wreck**).

Остальные режимы не меняются. Необязательно: пропуск роликов при запуске и исправление 3D-надписи
**FINAL LAP** для старых версий PCSX2 (в PCSX2 2.8 оно не нужно).

Подробное описание на английском — [README.md](README.md).

## Установка
1. Нужны PCSX2 2.x и одна из версий игры: PAL (SCES-50005, файл `patches/90DB90F1.pnach`) или NTSC-U
   (SLUS-20462, файл `patches/4C2D1E6D.pnach`). С другими эмуляторами, консолью и другими версиями игры патч
   не тестировался, работа там не гарантируется.
2. Скопируй файл для своей версии в папку патчей PCSX2. По умолчанию это `Документы\PCSX2\patches`,
   точный путь — в *Настройки → Папки*. Если файл с таким именем уже есть, допиши в него разделы из
   этого файла.
3. В списке игр: правый клик по игре → **Свойства → Патчи**, отметь **Arcade race settings**. Остальные пункты —
   по желанию.
4. Перезапусти игру.
