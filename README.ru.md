# WipEout Fusion — настройки аркадных заездов (патч для PCSX2)

Патч для **WipEout Fusion (PAL, SCES-50005)** в эмуляторе PCSX2. В одиночной **Arcade** после выбора корабля
открывается экран **race set-up**. На нём можно выставить:
- число кругов;
- число кораблей, до 16;
- щит свой и соперников;
- уровень прокачки соперников (можно сильнее твоего корабля);
- пит-лейн, воскрешение игрока и резиновую нить;
- что делать с уничтоженными соперниками: выбывают (**out**), воскрешаются (**respawn**) или остаются на
  трассе неподвижными остовами (**wreck**).

Остальные режимы не меняются. В том же файле есть необязательное исправление тормозов на 3D-надписи
**FINAL LAP**.

Подробное описание на английском — [README.md](README.md).

## Установка
1. Нужны PCSX2 2.x и PAL-версия игры (SCES-50005, CRC 90DB90F1). С другими эмуляторами, консолью и другими
   версиями игры патч не тестировался, работа там не гарантируется.
2. Скопируй `patches/90DB90F1.pnach` в папку патчей PCSX2. По умолчанию это `Документы\PCSX2\patches`,
   точный путь — в *Настройки → Папки*. Если файл с таким именем уже есть, допиши в него разделы из
   этого файла.
3. В списке игр: правый клик по игре → **Свойства → Патчи**, отметь **Arcade race settings**. Пункты
   **FINAL LAP fix** — по желанию.
4. Перезапусти игру.
